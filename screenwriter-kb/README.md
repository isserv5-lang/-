# 编剧灵感保险箱（Screenwriter KB）

> 本地优先 · 零云端上传 · Codex / Claude / Antigravity 三端共用 · AI 写作「精话锁」去油 · 互动影游多支线画布

你是不是也遇到过这些痛点？
- 喂给 AI 几本好小说学对白，结果 AI 学得不伦不类，还把盗版小说里的**手打防盗乱码章**也吃进去了；
- 写萌娃甜宠时，AI 把之前喂过的兽世/霸总台词混在一起乱炖；
- 让 AI 写正文时，旁白动不动就**“满屋杀气瞬间卡壳”“粗嗓门夹细了八度”“老脸涨成猪肝色”**，满嘴小品腔和 AI 油腻味；
- 想写互动影游或分歧短剧，几十个分支、好感度数值和结局容易写着写着出现**断头死胡同**。

**编剧灵感保险箱**就是为解决这些问题打造的本地桌面工作台：所有书库、人物卡、对白梗和剧本都在你自己的电脑里（默认 `D:\ScreenwriterKB`），同时支持**可视化网页操作**和 **AI 对话直接读写**。

---

## 它能帮你做什么？

1. **按题材分抽屉管理（物理隔离不乱炖）**
   - 预置 7 大常用抽屉：**萌娃团宠、兽世修罗场、都市爽文、重生复仇、悬疑推理、古言权谋、互动影游**，也可随时一键新建自定义抽屉。
   - 写什么题材就只开对应的抽屉，绝对不串味。

2. **智能喂书 & 自动踢除防盗坏章**
   - 支持导入 `.txt` 和 `.docx`（哪怕是纯文本改后缀的**伪 `.docx`** 也能直接读，自动识别 GBK / UTF-8 / UTF-16）。
   - 自动识别并隔离“正在手打中”“笔趣阁防盗提示”“半句异常截断”“后半章主角突变异世界”的坏章，**绝不拿脏章节污染你的灵感库**。

3. **10 句「试菜」校准口味 + 原文精确回读**
   - 导入新书后，先抽出 10~15 段高反差真原话让你点 **✓（喜欢）** 或 **✗（不喜欢）**，AI 摸准你的口味后再精读提炼，而不是盲目乱抓一通。
   - 每条入库对白都保留原书章号和行号，支持中文分词检索与一键回看原文上下文。

4. **「精话锁」刮油体检 + 防抄袭本地查重**
   - **精话锁**：自动区分“引号内的台词”和“引号外的旁白”。**把梗、毒舌、奶凶和笑点留给台词，引号外旁白只写平实动作**。内置 26 条高频 AI 油腻词黑名单，发现“瞬间卡壳”“涨成猪肝色”等立刻标红并给出真人改写建议；你在聊天或网页里随时可以拉黑新的讨厌词汇。
   - **本地查重**：交稿前零 Token 对比已导入书籍和梗库，防止无意照搬原句。

5. **互动影游多支线可视化画布**
   - 在网页里拖拽剧情节点，连线设置玩家选项、前置条件（如 `好感度>=60`）与好感/怀疑数值加减。
   - 自动诊断**断头死胡同**（没接结局的中间节点）和**孤立不可达节点**，支持保存修改历史对比，一键导出带跳转编号的剧本 Markdown。

## 3 分钟快速开始

### 第一步：准备环境（首次使用）
需要 Windows 电脑已安装 `uv` 与 Python 3.12：

```powershell
cd screenwriter-kb
uv sync --python 3.12 --all-extras
uv run --python 3.12 python scripts/connect_ai_clients.py
```

运行后会自动完成两件事：
1. 在 `D:\ScreenwriterKB` 初始化干净的本地数据库（含 7 个空抽屉、26 条精话锁规则和 1 个演示用的 4 节点互动小剧本）；
2. 自动把本地 MCP 服务和 `novel-craft-feeder` 技能接通到 **Codex、Claude Desktop、Antigravity**（修改前会自动在原配置旁生成 `.bak` 备份）。

> 重启一次你的 AI 客户端，就能在聊天里直接让它帮你喂书、试菜、写稿和过精话锁！

### 第二步：打开本地可视化工作台
- **最简单方式**：直接双击 **`D:\ScreenwriterKB\打开可视化知识库.cmd`**（或仓库里的 `启动可视化面板.cmd`）。
- 浏览器会自动打开 `http://127.0.0.1:8765`，包含四大中文工作区：
  1. **类型抽屉 & 书架**：建抽屉、粘贴本地小说路径导入、看章节健康红绿灯、点章节逐行看原文；
  2. **试菜台 & 灵感库**：给候选原话打 ✓/✗、搜好梗、管理人物声音卡和名场面钩子；
  3. **精话锁刮油台**：粘贴草稿一键标红 AI 油腻旁白、管理黑名单、做原创度查重；
  4. **互动影游画布**：拖拽剧情节点、连分支选项、看死胡同提醒、导出完整台本。

## 在 AI 聊天里怎么用？（口头指令示例）

接通 MCP 后，你可以像跟助手说话一样直接吩咐 Codex / Claude / Antigravity：
- **喂新书**：“帮我把 `D:\小说\某某萌娃.txt` 喂进萌娃团宠抽屉，先报一下有没有防盗坏章，再抽 10 句原话让我试菜。”
- **写台本**：“打开萌娃团宠抽屉，参考里面欢脱互怼的节奏写一段 300 字新对白，写完自己跑一遍精话锁和查重再给我看。”
- **永久拉黑讨厌词**：“以后不许在旁白里出现‘眼底闪过一丝戏谑’，帮我加进精话锁黑名单。”
- **写互动影游**：“帮我在互动影游里建一个豪门试镜主题的多支线剧本，设置好感度和警惕值两个变量，写完检查一遍别留死胡同。”

## 隐私与安全说明
- **100% 本地存储**：你的小说文件、拆分文本、`kb.sqlite` 索引、导出的 Markdown 都在你本机的 `D:\ScreenwriterKB`（或你通过 `SWKB_DATA_DIR` 指定的目录）。
- **代码仓库干净**：本仓库 `.gitignore` 已默认屏蔽数据库文件与虚拟环境，不会上传任何个人书籍或客户端密钥。
